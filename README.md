# Рядом — главная страница

React + Vite. Главная страница собрана по макету Figma: шапка, баннер, преимущества, категории, популярные товары, подписка и подвал.

## Запуск

```bash
pnpm install
pnpm dev
```

Если используете npm:

```bash
npm install
npm run dev
```

## Изображения

Ссылки на изображения и SVG из исходного Figma-макета собраны в `src/assets/figmaAssets.js`. Сейчас они подключены напрямую с сервера Figma; для долгосрочного использования сохраните эти файлы локально в `src/assets` и замените URL на локальные импорты.
